### Důležité příkazy, aliasy etc

#### kubectl

základní kubernetes client


#### dbgpod

Přihlásí Vás do debgu podu v namespace debug-ns, ze kterého můžete testovat testovací aplikaci


#### kubens

Automaticky změní namespace, nebo je vypíše


#### kubersh <jmeno podu>

Pokud image daného podu/defaultního kontejneru obsahuje bash, přihlásí Vás do podu
